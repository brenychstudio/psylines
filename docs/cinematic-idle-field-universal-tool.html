Cinematic Idle Field

Документація reusable UX-системи для сторінок, які під час бездіяльності не просто зникають, а переходять у кінематографічний стан тиші: текст стишується, розпливається, починає поводитись як примара, а зображення стають більш присутніми.

1. Призначення

Cinematic Idle Field - це поведінковий шар для довгих, атмосферних або contemplative сторінок. Він реагує не на натискання кнопки, а на відсутність дії: коли користувач перестає рухати мишкою, скролити або взаємодіяти, сторінка поступово стишується.

Мета інструмента - не сховати контент, а змінити стан сприйняття. Текст стає менш буквальним і більш примарним, другорядні деталі відходять у поле, а образи можуть залишатися активними або навіть ставати сильнішими.

Ключовий принцип: idle-ефект має відчуватися як повільна зміна стану сторінки, а не як технічний fade-out.

2. UX-Контракт

  • Ефект входить поступово, кількома фазами, без різкого blur або snap.
  • Текст не просто зникає, а втрачає фокус, розпливається і дрейфує.
  • Зображення не повинні темніти, якщо задум сторінки вимагає їхньої присутності.
  • Повернення до нормального стану після руху або скролу має бути плавним.
  • Система повинна поважати prefers-reduced-motion.
  • Ефект має бути reusable через data-attributes, без прив'язки до конкретної сторінки.

3. State Machine

Поточна реалізація використовує п'ять станів. Це дозволяє уникнути різкого переходу з повністю читабельної сторінки у повністю розмиту.

awake settling idle dreaming waking
Стан Що відбувається Візуальна роль
awake Нормальний стан сторінки після активності користувача. Повна читабельність, стандартний layout.
settling Перша фаза тиші після idle delay. Контент м'яко стишується, blur мінімальний.
idle Середня фаза бездіяльності. Текст помітно втрачає фокус, але ще читається як слід.
dreaming Глибока фаза після довшої бездіяльності. Текст галюцинує, дрейфує, розпливається; зображення лишаються присутніми.
waking Плавне повернення після руху, скролу, touch або клавіатури. Без різкого snap-back; сторінка повільно збирається назад.

4. HTML API

Інструмент працює через root-контейнер та child-елементи, позначені ролями. Це дозволяє підключити поведінку до будь-якої сторінки без переписування її структури. 

<main
  data-cinematic-idle-root
  data-cinematic-idle-delay="5600"
  data-cinematic-idle-reduced-delay="9000"
  data-cinematic-idle-settle-duration="2800"
  data-cinematic-idle-dream-duration="7600"
  data-cinematic-idle-wake-duration="3600"
>
  <h1 data-cinematic-idle="anchor">The body appears from gesture.</h1>
  <p data-cinematic-idle="voice">Long readable body copy.</p>
  <article data-cinematic-idle="line">Repeated structured row.</article>
  <figure data-cinematic-idle="image">...</figure>
</main>

Root Attributes

Attribute Default Meaning
data-cinematic-idle-root required Позначає область сторінки, на яку поширюється idle behavior.
data-cinematic-idle-delay 5600 Час бездіяльності перед входом у settling.
data-cinematic-idle-reduced-delay 9000 Delay для reduced-motion користувачів.
data-cinematic-idle-settle-duration 2600 Скільки триває перехід settling -> idle.
data-cinematic-idle-dream-duration 6400 Коли після початку idle запускати глибшу фазу dreaming.
data-cinematic-idle-wake-duration 3200 Тривалість плавного повернення в awake.

5. Role API

Кожен елемент може отримати роль. Роль визначає, як саме він поводиться під час idle-фаз.

Role Recommended Use Idle Behavior
anchor H1, H2, великі statement-заголовки. Повільно розфокусується, отримує ghost text-shadow.
voice Основний абзац, lead, authored copy. Стишується сильніше, розпливається і дрейфує.
line Рядки таблиць, steps, metadata rows. Найшвидше відходить у поле, найменш активний у deep idle.
detail Kickers, labels, формули, дрібні пояснення. Стихає майже до примарного стану.
image Головні зображення або об'єкти. Залишається активним, може ставати трохи яскравішим.
field Interactive maps, spatial fields, WebGL/canvas-adjacent surfaces. Stays present with minimal drift; use it for the living environment, not dissolving text.
trace Другорядні образи, фрагменти, матеріальні сліди. Не темніє; може м'яко посилювати присутність.
presence Елементи, які мають залишатися майже стабільними. Мінімальні зміни, легкий cinematic drift.
contact Email, телефон, прямі контактні дані. Залишається видимим і доступним; стишується як світловий сигнал, без сильного blur.
action CTA, навігаційні маршрути, кнопки, social links. Стишується повільно, але лишається достатньо видимим для взаємодії.

6. Timing Model

Таймінги мають бути довгими. Короткі transition-и роблять ефект технічним і різким. Для cinematic behavior краще думати не в сотнях мілісекунд, а в секундах.

Параметр М'який режим Глибокий режим
Idle delay 4500-6500ms 6500-9000ms
Settle duration 2200-3200ms 3200-4200ms
Dream trigger 6000-8000ms 9000-14000ms
Wake duration 2800-4200ms 4200-5600ms

7. Implementation Notes

JavaScript Responsibilities

  • Find every [data-cinematic-idle-root].
  • Inject a passive visual veil inside each root.
  • Calculate per-element delays using distance, role weight, order and hash jitter.
  • Move root state through awake, settling, idle, dreaming, waking.
  • Listen for activity events: pointer, wheel, scroll, keydown, touch.
  • Respect hidden documents and focus-within states.

CSS Responsibilities

  • Define the visual behavior of each state.
  • Keep text and images tuned separately.
  • Use long transition durations and cinematic easing.
  • Disable animations in reduced-motion mode.
  • Avoid making all elements fade/blur at the same time.

8. Accessibility Rules

  • Never remove content from the DOM.
  • Do not use display: none or visibility: hidden for readable content.
  • When the root has :focus-within, do not enter idle.
  • Respect prefers-reduced-motion: reduce.
  • Keep navigation, top buttons and essential recovery paths available.
  • Idle effects should be reversible through ordinary interaction.

9. Tuning Recipes

If blur appears too suddenly

  • Add a settling phase with blur under 0.8px.
  • Increase data-cinematic-idle-settle-duration.
  • Reduce enter-delay jitter if the page feels chaotic.

If the page becomes unreadable too fast

  • Raise opacity for anchor and voice in idle.
  • Delay dreaming by increasing data-cinematic-idle-dream-duration.
  • Keep deep hallucination only for dreaming, not settling.

If images feel inactive

  • Do not lower image opacity in idle.
  • Use brightness(1.03) and saturate(1.05) lightly.
  • Use scale below 1.02 to avoid layout drama.

If wake feels abrupt

  • Increase data-cinematic-idle-wake-duration.
  • Use a softer wake easing curve.
  • Keep the waking state long enough that repeated micro-movements do not snap the page.

12. Contact Page Adaptation

На контактних сторінках не можна поводитися з email або кнопками так само, як із фоновим текстом. Контактні дані мають стишуватись атмосферно, але залишатися доступними. Для цього використовуються ролі contact і action. 

<section
  data-cinematic-idle-root
  data-cinematic-idle-delay="6200"
  data-cinematic-idle-settle-duration="3000"
  data-cinematic-idle-dream-duration="8200"
  data-cinematic-idle-wake-duration="3600"
>
  <h1 data-cinematic-idle="anchor">Contact the studio.</h1>
  <p data-cinematic-idle="voice">For collector inquiries...</p>
  <a class="contact-email" href="mailto:studio@example.com" data-cinematic-idle="contact">
    studio@example.com
  </a>
  <div data-cinematic-idle="action">
    <a href="mailto:studio@example.com">Open mail</a>
    <button type="button">Copy email</button>
  </div>
</section>

13. Global Route Scaling

For a full site, keep one state machine but adapt the role map per route. The effect should support the page contract instead of applying one generic blur to everything.

Route type Idle behavior Do not fade
Home Threshold copy dissolves; selected artwork and living field stay present. Active work image, route actions, next gesture.
Works Archive metadata quiets down so object surfaces become more dominant. Artwork media, filters, view toggles, work links.
Series Panel language softens while the constellation and WebGL atmosphere keep breathing. Active node image, map interaction, open actions.
Immersive Entrance copy becomes threshold-like and atmospheric. Enter field CTA and return routes.
Contact Secondary explanation recedes. Email, copy button, direct links.

Avoid assigning an idle role directly to elements whose transform is already used for spatial layout, camera panning, drag maps, carousel positioning or physics. Put the role on inner text/media elements instead.

14. QA Checklist

  • Wait for idle delay: page should enter settling gently.
  • Wait longer: text should reach dreaming without sudden jump.
  • Move mouse once: page should begin waking, not snap instantly.
  • Scroll: recovery should remain smooth.
  • Focus keyboard controls: idle should not interrupt focus interaction.
  • Enable reduced motion: animations and long hallucination drift should stop.
  • Check mobile: touch and scroll should wake the page reliably.
