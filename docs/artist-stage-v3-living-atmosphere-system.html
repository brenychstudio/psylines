ARTIST STAGE v3 / living atmosphere documentation

Система живої атмосфери, яка підлаштовує фон під роботи.

У цьому проєкті фон сайту не є статичним декоративним шаром. Він змінюється разом із активною роботою, її контекстом, станом сторінки та взаємодією користувача, створюючи відчуття живого, безперервного атмосферного поля навколо мистецтва.

1. Що саме ми реалізували

Видимий результат

Коли користувач відкриває Home, Works або Work Detail, фон отримує кольоровий wash, glow, shadow та оптичну глибину, які відповідають конкретній роботі або групі робіт.

Через це сайт читається не як “сторінка з картинкою”, а як середовище, в якому сама робота формує атмосферу сцени.

Важливе уточнення

Поточна система не витягує кольори автоматично з файлів зображень. Вона author-driven: для кожної важливої роботи ми вручну задаємо атмосферний профіль.

Це було свідоме рішення: контроль художнього результату важливіший за “автоматичну” палітру, яка могла б дати технічно коректний, але естетично слабший результат.

2. Як система розвивалась по етапах

V3-17 / V3-19
Artwork Atmosphere Field Lite

З’явилися ручні atmosphere profiles для окремих робіт і глобальний fixed field layer, який став візуально відчутним, а не суто технічним.

V3-20
Living Atmosphere Orchestrator Lite

Атмосфера перестала бути простим hover-ефектом і стала єдиною клієнтською системою, яка керує current state, target state, active artwork, stillness і inspecting mode.

V3-21
Section State Atmosphere

Вплив на атмосферу почали мати не тільки роботи, а й секції сторінок: Home threshold, Works field, Works index, Artist statement тощо.

V3-22
Route Handoff Memory

Атмосфера почала “перетікати” між сторінками. Попередня робота лишає residue, а новий route плавно приймає керування без відчуття повного скидання.

V3-27
Psychological Presence Curves

Поведінка атмосфери стала відрізнятися не лише кольором, а й характером: tension, calm, density, shadow weight, halo response і breath response для різних робіт.

3. Архітектура системи

Route mood (server / base shell) -> ArtworkAtmosphereBridge sets page target -> Living Atmosphere Orchestrator receives target -> CSS variables on <html> interpolate toward target profile -> fixed .site-artwork-atmosphere-field redraws background washes -> section states + route memory + stillness + inspecting refine behavior

A. Base mood layer

На рівні route сайт уже має базовий mood: `metaBodies`, `nightWater`, `studies`, `collector`, `immersive`. Це стартова атмосфера shell before artwork refinement.

B. Artwork profile layer

Активна робота задає authored profile з параметрами `wash`, `washStrong`, `glow`, `shadow`, `shadowWash`, `accent`, `pressure`, `density`, `fieldOpacity`, `focusedOpacity`, `inspectOpacity`.

C. Orchestrator layer

Єдиний client-side orchestrator веде current state, target state, focus override, active section, route handoff, stillness і inspect mode.

D. Render layer

Візуальний фон рендериться через fixed `.site-artwork-atmosphere-field`, який живе в глобальному shell і використовує CSS variables для зміни градієнтів, opacity, blur, scale і drift.

5. Як background реально підлаштовується під роботу

Крок 1. Сторінка визначає target artwork

Наприклад, Home стартує з `MT-3`, Works бере або активну роботу в viewport, або hover/focus target, а Work Detail задає конкретний slug сторінки.

Крок 2. Bridge передає slug у orchestrator

`ArtworkAtmosphereBridge` передає slug як target. Якщо orchestrator уже активний, він одразу починає м’який drift до нового профілю. Якщо ні, bridge ставить fallback values.

Крок 3. CSS variables оновлюються на root

Профіль записує значення у `--artwork-wash`, `--artwork-glow`, `--artwork-shadow-wash`, `--artwork-field-opacity` та інші токени.

Крок 4. Fixed field layer перерисовує атмосферу

Глобальний шар `.site-artwork-atmosphere-field` використовує radial gradients, blur, scale і opacity, тому фон буквально змінює свій колір, глибину і характер під активну роботу.

6. Чим система “жива”, а не просто кольорова

Section states

Одна й та сама робота може відчуватися інакше в Home threshold, у Works field або в Artist statement, бо секція модулює density, calm, saturation, blur і drift.

Route handoff memory

При переході між сторінками атмосфера не “обнуляється”. Попередня робота лишає короткий residue, а новий route приймає поле поступово.

Presence / stillness

Коли користувач завмирає, поле може стати тихішим, глибшим або спокійнішим. Це дає відчуття breathing environment замість плоского фону.

Psychological curves

Різні роботи мають різний temperament. `MT-3` росте тихо, `MT-2` працює щільніше й напруженіше, `Figure in Ash Light` тримає теплішу suspended атмосферу.

7. Приклади профілів

Робота Візуальний характер Поведінковий характер
MT-3 Зелено-оливковий wash, теплий vegetal glow, м’яка темна глибина. Спокійніше зростання, більша calm response, повільніший breath.
MT-1 Червонувато-глиняний wash, теплий accent, важчий shadow. Вищий pressure, сильніший focus pull, щільніша присутність.

Quiet Red Interval Більш стриманий red-brown field, глибший submerged wash. Повільніший response speed, м’якший interval-temperament.

8. Чому ми не використовували автоматичне color extraction

  • Автоматична палітра не гарантує художньо правильний результат.
  • Нам потрібен був не просто “середній колір картинки”, а відчуття сцени.
  • Ручні профілі дозволяють окремо керувати wash, glow, shadow і behavioral temperament.
  • Це дає стабільний, передбачуваний вигляд на всіх ключових маршрутах.

У майбутньому automatic extraction можна додати як допоміжний інструмент для authoring, але не як головне джерело truth для фінального живого поля.

9. Що система не робить зараз

  • Не аналізує зображення AI-моделлю.
  • Не витягує палітру автоматично з cover файлів.
  • Не залежить від WebGL, AR чи XR для core web behavior.
  • Не зберігає поведінкові дані користувача для аналітики.
  • Не є “psychological tracking”; це authored visual dramaturgy.
  • Не замінює майбутній visual sweep або content author review.

10. Поточний підсумок

Система living atmosphere вже є однією з ключових відмінностей цього проєкту. Вона поєднує route mood, artwork-driven color field, section states, route memory і presence curves в одну web-first атмосферну оболонку.

Головне: background тут не просто “підфарбований” під зображення. Він працює як жива частина художньої сцени, яка підсилює роботу, не з’їдаючи її і не перетворюючи сайт на стандартну галерею з картками.
